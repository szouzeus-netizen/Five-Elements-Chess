# 五行阵 ChatGPT App starter

这是按 Cloudflare 官方 Interactive ChatGPT App 架构制作的第一阶段骨架：Worker + MCP `/mcp` + React/Vite UI + Durable Object/Agents 状态通道。

**注意：这不是最终规则引擎。** 吃子、保护链、大棋子限制、炼化、五种上级五行能力、三种胜利条件等会在规则确认后逐项加入。

Cloudflare 当前的「Upload your static files」只适合静态站点；这个项目需要 Worker/MCP，因此建议通过 GitHub 连接部署。

官方参考：
https://developers.cloudflare.com/workers/demos/chatgpt-app/
